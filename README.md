# Phragmites Website

Website for our FIRST LEGO League innovation project on invasive Phragmites.

## Files

- `index.html` – page content (sections: Problem, Research, Solution, Experts, Team, Sources)
- `styles.css` – colors, layout, and mobile styles
- `script.js` – mobile menu and footer year

## Viewing the site

Open `index.html` in a web browser. No build step or install is needed.

## Editing

Look for `TODO` comments in `index.html` — those mark the places to fill in with the team's own research, solution, experts, and sources.
